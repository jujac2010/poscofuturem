제철소·물류센터 현장의 5대 전동 지게차를 디지털 트윈으로 표현하고, 배터리·온도·진동 데이터를 실시간으로 시뮬레이션해 이상 징후를 조기에 확인하는 시연형 관제 프로젝트입니다.

01. 문제와 가설

문제 상황

수기 기록과 경험 의존 운영

기존 지게차 운영은 작업자의 경험과 수기 기록에 의존하여 배터리 부족, 과열, 진동 이상을 사전에 파악하기 어렵습니다. 그 결과 작업 중단과 긴급 정비가 발생하고 관리자가 전체 장비 상태를 한눈에 확인하기 어렵습니다.

핵심 가설

상태를 한 화면에 연결하면 대응이 빨라진다

지게차 위치·운행 상태·센서 추이·이벤트 로그를 하나의 현장 배치도에 연결하면 관리자는 이상 징후를 더 빨리 발견하고 점검 우선순위를 판단할 수 있습니다.

04. 기술·데이터 구조

React / TypeScript→상태 관리→센서 시뮬레이터→배치도·카드·그래프→이벤트 로그·진단 리포트

선택 이유

React는 지도·카드·상세 패널처럼 상태가 연결된 화면을 컴포넌트 단위로 구성하기 좋고, TypeScript는 센서 데이터 구조와 상태 전이를 안전하게 관리합니다. 반응형 CSS로 데스크톱 관제 화면과 모바일 점검 화면을 함께 대응합니다.

확장 방향

현재는 시연용 메모리 상태를 사용하고, 실제 운영 시 IoT 게이트웨이·PLC·MES API를 연결합니다. 데이터베이스에는 장비·센서·이벤트 이력을 저장하고 인증/권한으로 현장·관리자 접근을 분리합니다.

영역선택 기술대안 검토
UIReact + TypeScriptNext.js는 서버 라우팅/배포가 필요할 때 확장
시각화SVG/CSS 기반 현장 지도, 경량 차트대규모 시계열은 Recharts/ECharts 도입
실시간 연동시뮬레이터 상태 업데이트운영 단계에서 WebSocket/MQTT/REST API
저장·보안프로토타입은 로컬 상태운영 단계에서 DB, SSO, RBAC, 감사 로그
